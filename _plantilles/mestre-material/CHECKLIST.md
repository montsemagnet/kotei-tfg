# Checklist — nou material / observació

Marca cada punt quan estigui fet.

## Abans de començar

- [ ] He **copiat** `mestre-material` (no he tocat l’original).
- [ ] He reanomenat la còpia (exemple: `I1-P1-M1` = itinerari 1, parada 1, material 1).

## Contingut mínim

- [ ] Omplert `01-fitxa-material.md`
- [ ] Omplert `02-observacions.md` (text principal)
- [ ] Indicat a **quina parada** va lligat (codi, ex.: `I1-P1`)
- [ ] Almenys una imatge d’òptica a `03-optica/` (si el material és petrogràfic)
  - o imatges equivalents a `06-altres/` si és una observació d’un altre tipus (espècie, etc.)

## Contingut opcional (petrografia)

- [ ] Microscopia electrònica a `04-electronica/`
- [ ] Espectres a `05-espectres/` (parelles amb les files d’electrònica, si escau)
- [ ] Taula de percentatges / composicions a la fitxa

## Abans d’entregar

- [ ] Peus / `alt` de cada imatge
- [ ] Crèdits / data (si cal)
- [ ] Noms de fitxer sense espais ni accents
- [ ] Entrego la carpeta completa
