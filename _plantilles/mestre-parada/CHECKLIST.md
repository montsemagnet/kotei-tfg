# Checklist — nova parada

Marca cada punt quan estigui fet.

## Abans de començar

- [ ] He **copiat** `mestre-parada` (no he tocat l’original).
- [ ] He reanomenat la còpia (exemple: `I1-P03` = itinerari 1, parada 3).

## Contingut mínim

- [ ] Omplert `01-fitxa-parada.md`
- [ ] Omplert `02-geologia.md` (text + peus de figura)
- [ ] Fotos de geologia a `05-figures-geologia/` (o marcat “encara no”)
- [ ] Galeria d’aflorament a `04-galeria-aflorament/` (entre 1 i 8 fotos)
- [ ] Mapa a `08-mapa-qgis/` (QGIS o PDF) o indicat mapa compartit amb una altra parada

## Contingut opcional

- [ ] Omplert `03-geobotanica.md`
- [ ] Figures de flora a `06-figures-geobotanica/`
- [ ] Vídeo a `07-video/`

## Abans d’entregar

- [ ] Coordenades revisades
- [ ] Crèdits / data a les fotos (si cal)
- [ ] Noms de fitxer sense espais ni accents
- [ ] Entrego la carpeta completa
