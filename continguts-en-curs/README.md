# Continguts en curs

Aquí van les còpies de treball de cada parada o itinerari (exemple: `I1-P3`).

Les plantilles netes són a `_plantilles/` — no les ompliu.

## Flux

1. `npm run nova-parada -- preparar I1-P3`
2. Omplir aquesta carpeta (`I1-P3/`, etc.)
3. `npm run nova-parada -- implementar I1-P3`
